## Release validation

- Build and publication verifiers passed for 34 pages, including unique titles and descriptions, canonical and social URLs, parsed JSON-LD, sitemap consistency, internal destinations, fragments and assets. No production dependencies were added.
- Chromium and WebKit each checked all 34 routes with JavaScript enabled and disabled. All routes passed horizontal overflow checks at 1440, 390 and 320 pixels. Navigation, keyboard focus, clipboard, email brief, analytics payload and motion regression checks passed. Mobile and desktop captures were compared. The error page is noindex and unknown routes returned HTTP 404.
- axe-core reported zero automated WCAG 2.0/2.1 A/AA violations across all 34 publication files at 390 pixels. Each main region had one H1 and no skipped heading levels in the desktop and mobile audit.
- In a single paired mobile Lighthouse run on local HTTP, the homepage performance score changed from 91 to 97 and LCP from 3.6 s to 2.6 s. CLS remained 0 and total blocking time remained 0 ms. Transfer grew from 405 to 409 KiB. Both runs scored 100 for accessibility, best practices and SEO. These are lab measurements.
